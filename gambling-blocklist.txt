# Format: Domain + wildcard for subdomains (two entries per site)
# Each domain needs both entries to block the main domain AND all subdomains
#
# Example: blocking "bet365.com" requires both:
#   bet365.com          (blocks the main domain)
#   *.bet365.com        (blocks all subdomains like www.bet365.com, mobile.bet365.com, etc.)
